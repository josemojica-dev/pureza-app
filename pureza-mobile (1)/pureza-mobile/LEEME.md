# Pureza v3

Novedades: días limpios automáticos, consecuencias constructivas al recaer, premios por metas,
ánimo diario, contador de pasos, botón de impulso (10 min) y widget con pasos y próximo premio.

## Compilar
Sube este zip a tu repositorio de GitHub (reemplaza al anterior). En Actions se compila el APK.

## Importante
Esta versión usa una llave de firma fija: desde aquí, cada APK nuevo se instala ENCIMA del anterior sin perder datos.
La primera vez hay que desinstalar la versión vieja (usa otra llave). Luego, en la app: Personalizar > Corregir mi racha.
